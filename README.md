# KronKollen
Kronkollen is an app to easlity track expenses across categories, timespands, banks and more. It takes an xlsx file, which can be exported from most banks.

Auto-categoerize common expenses by adding keywords from trqnsactions, such as ICA= Food, SJ = Transport etc. 

it supports time-grouping and sub-categories, such as (sports) with sub (bike, run, downhill etc)
